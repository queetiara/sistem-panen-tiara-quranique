# Sistem Pencatatan Hasil Panen Digital

Program sederhana menggunakan Python untuk menghitung total hasil panen dan harga hasil panen setelah diberikan diskon.

## Cara Menjalankan Program
1. Buka file `panen.py`.
2. Jalankan program menggunakan Python.
3. Program akan menghitung total hasil panen.
4. Hasil perhitungan akan ditampilkan pada terminal.
